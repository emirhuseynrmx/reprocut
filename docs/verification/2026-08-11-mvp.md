# ReproCut MVP verification record

Date: 2026-08-11  
Scope: file-reduction MVP on branch `feat/reprocut-mvp`

## Outcome

The implemented slice stabilizes a repeatable failure, minimizes regular files in disposable project copies, verifies the result three times, and publishes a JSON/report/reproducer artifact without editing the source tree.

It does not yet include manifest reduction, syntax reduction, resume, a persistent cache, or a parallel engine.

## Safety and correctness boundary

- Source files are inventoried read-only; mutations occur only in temporary candidates or the new output tree.
- Symbolic links are not followed. Symlink creation behavior can still vary with Windows privileges.
- User command output is bounded in memory while both pipes continue draining.
- Timeout cleanup currently covers the direct child, not its complete descendant tree.
- Arbitrary commands execute with the user's host permissions. Temporary directories are not a malware sandbox.
- The oracle currently identifies normalized stderr plus exit state. Stdout is captured but is not part of the fingerprint.
- Output existence is checked before work and immediately before rename. There is no cross-process publication lock, so a concurrent creator race can remain platform-dependent.
- A truncation or timeout is inconclusive and can never approve a deletion.

## Deferred design capabilities

- manifest/lockfile-aware reducers;
- syntax/AST-aware reducers;
- persistent state and resume;
- parallel frontier scheduling;
- descendant process-tree control;
- hostile-code containment;
- signed prebuilt releases and measured cross-machine performance claims.
